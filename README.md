# Pacific Code Labs design system

Shared semantic light/dark tokens, typography, accessible Radix primitives,
buttons, skeleton layouts and drawers used by the public landing and private admin.

Consumers install the TypeScript source with
`github:Pacific-Code-Labs/pacific-code-labs-design-system#v0.1.0`.
Import `@pcl/design-system/styles.css` once, and components from
`@pcl/design-system` or `@pcl/design-system/ui/<component>`.
Run `pnpm install` and `pnpm typecheck`. Release changes with a new version/tag.
